# June-September 2026 update audit

Reviewed on 2026-09-09. Baseline: `55981ca`, whose latest snapshots were dated 2026-05-12. Each subsequent date was prepared for both core patch groups before advancing to the next date.

## Sources and date coverage

Blizzard's monthly retail changelogs were checked for missing core balance dates:

| Official source | Dates added | Review result |
| --- | --- | --- |
| [May 2026](https://overwatch.blizzard.com/en-us/news/patch-notes/live/2026/05) | None after May 12 | Later entries did not add core balance snapshots. |
| [June 2026](https://overwatch.blizzard.com/en-us/news/patch-notes/live/2026/06) | June 16, 23, 25 | Shion and Neon Junction launch, hero/perk changes, map tuning, Execution hotfix. |

| [September 2026](https://overwatch.blizzard.com/en-us/news/patch-notes/live/2026/09) | September 8 | Latest core balance patch found; mode-specific health and cooldown changes checked separately. |

Sixteen snapshots were added. June 30's Community Crafted changes belong to Arcade, not core hero balance. July 30's temporary Quick Play Hacked/Open Queue weekend is not a permanent change to the tracked 6v6 ruleset. Neither was copied into core snapshots. Stadium, event rewards, cosmetic changes, and minor bug fixes are excluded.

## Comparison review

[Consecutive snapshot diffs](2026-09-update-diffs.md) contain the complete raw comparisons after backfilling. The implementation's date-keyed mappings are in `scripts/update_summer_2026.mjs`.

- June 16: checked every numerical hero/perk change, both removed perks, Hazard's tier swaps, Shion's release boundary, and Neon Junction's initial version. Removed both stale ammo keys on Ashe's Viper's Sting and the fuel refund on Headbutt. Ramattra's Annihilation extension stays at one second while his ordinary extension becomes two.
- June 23: Neon Junction becomes map version 2. This represents the payload-speed and wait-time tuning without inventing unpublished seconds or speeds; it is not an unadded map change.
- June 25: Execution projectile size and recovery change only; other Shion launch values remain intact.
- July 14: checked every core hero entry. Inspire's 45 healing over its existing four seconds is 11.25 HPS, with a separate 12-healing trigger. Whiplash remains a perk. Freja's 5.5 shots/s is represented as a reciprocal recovery time.
- August 11: all five perk replacements remove the old entries. Focused Rush moves to Major. D.Mon is introduced as Stalwart; Flanker health-pack healing changes in both groups. Busan, Eichenwalde, and Paraiso each increment their map version. Mauga's explicitly 5v5 cooldown change is not applied to 6v6.
- August 12: checked all five D.Mon numeric hotfix fields.
- August 14: checked all four D.Mon cast/recovery changes and both Jetpack Cat changes. The nonnumeric mech-head hitbox adjustment remains unresolved below.
- September 8: checked each core hero entry. D.Mon's armor change is 6v6-only; D.Va health, Winston barrier cooldown, and Zarya personal-barrier cooldown are 5v5-only. Brigitte's health-to-armor shift is separate from perk data. Vendetta's outdated average swing rate is omitted rather than used to fabricate current DPS.

Unqualified core hero changes are treated as shared unless an existing mode-specific baseline conflicts. Sigma's July shield value and Mauga's September armor value preserve their distinct 6v6 baselines pending confirmation; those exceptions are explicitly recorded in `unadded_changes.md`. This is an applicability assumption, not proof that all unchanged 6v6 baselines are current.

## Baselines and calculations

[Shion](https://overwatch.fandom.com/wiki/Shion) and [D.Mon](https://overwatch.fandom.com/wiki/D.Mon) wiki numeric data supplied fields absent from Blizzard's notes. Launch snapshots reverse the subsequent official deltas; current wiki numbers were not blindly copied to launch. Ability timing and resource details not changed by the covered notes are provisional wiki baselines, not independently measured gameplay data.

- Shion primary fire calculates to 140 DPS and 105 DPS including reload, matching the wiki. Execution's 14 rounds at 10 damage produce calculated 140-damage volleys and 280 critical volleys.
- D.Mon Plasma Saber calculates to 91.2 DPS at launch, 98.8 after August 12, and 91.2 after September 8. Fusion Repeater is 135 DPS at launch and 144 after August 12. These are active-firing rates, not cooldown-averaged damage.
- D.Mon pilot fire calculates to 93.756 DPS from the wiki's rounded 7.813 shots/s. The wiki reports 93.75 DPS; the small difference is input rounding, not a different weapon model. Reload-inclusive DPS is deliberately absent because no supported reload time was found.
- D.Mon pilot health is not tagged as mech health. Unverified 6v6 base health is omitted, and the calculation layer does not label the known armor component as total health.
- Echo's Full Salvo retains its existing percentage field and also records the explicit additional projectile count, 3 to 2. Both represent the same six-projectile baseline.
- Jetpack Cat retains the project's center/paw pellet model. June's per-pellet change scales the double-strength center pellet and total healing consistently; September reverses those values. Carrying regeneration is derived from the recorded base rate divided by the new slowdown, with the old inconsistent baseline noted as unresolved.

Newly exposed old values are backfilled only into applicable existing entries. Explicit introduction boundaries are used where established, including perks, new heroes, and February/April 2026 abilities. Other newly tracked fields are bounded to the last audited May 12 snapshot; their earlier history is not certified by this update. Existing conflicting numerical history is retained rather than silently rewritten.

## Remaining limitations

The dated additions to `unadded_changes.md` are part of this audit, not a claim of complete numeric coverage. They list source-versus-history conflicts, unknown launch fields, unmeasured geometry/acceleration, and queue-specific systems that are not modeled. Schema/unit validation does not prove the factual correctness of inherited snapshots.

## Reproduction and verification

The one-time migration is intentionally pinned to baseline `55981ca`; do not rerun it on a later checkout. For audit reproduction, use a separate checkout at that baseline, copy the migration scripts there, and cache the source HTML under `%TEMP%/overwatch-september-audit/` as `05.html` through `09.html`. The icon script additionally expects the nine listed hero pages there, using their URL slugs as filenames. It fails if an expected official icon is missing.

Run `node scripts/update_summer_2026.mjs`, then `python scripts/update_summer_icons.py`. `scripts/extract_patch_notes.py` reads a cached month plus an optional date for human source review. Source pages can change after the audit date; the checked-in mappings and comparisons preserve the actual update decisions.

Verification: `npm test` passes all 267 tests, including 14 new regression tests covering chronology, hero boundaries, map versions, perk removal/tiering, official asset origins, mode-specific changes, health totals, and the actual primary-fire calculation functions. Existing Vite/esbuild configuration warnings remain unchanged.

`npx tsc --noEmit` does not pass: the existing configuration cannot resolve test dependencies and `main.ts` uses undeclared browser globals. With bundler module resolution, all 124 remaining diagnostics are identical when checking the original baseline `main.ts` versus the updated file; no new diagnostics were introduced. The existing Pages workflow invokes `npx tsc`, so a successful Git push does not establish a successful website deployment. Deployment repair is outside this data update.
